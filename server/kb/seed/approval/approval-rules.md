# 三级审批规则与关注点

## 一级审批：部门负责人

**关注重点**：
- 是否本部门职责范围内？
- 本部门人力是否足够支撑？
- 对部门年度目标的价值

**常见驳回原因**：
- 人力已饱和，无法分配资源
- 与部门目标关联弱

## 二级审批：产品/技术委员会

**关注重点**：
- 市场机会是否真实？数据有无依据？
- 技术路线是否可行？风险是否可控？
- 差异化是否清晰？
- ROI 是否合理？

**常见驳回原因**：
- 市场分析缺乏数据支撑
- 技术路线过于乐观
- 与现有产品线冲突
- 预算无明细依据

## 三级审批：公司决策层

**关注重点**：
- 战略价值：是否符合公司方向？
- 总投入与预期回报
- 最大风险及止损方案
- 优先级：为什么现在做？

**常见附条件立项前提**：
- PoC 验证核心指标
- 锁定 2 家标杆客户意向
- MVP 预算控制在指定范围内

## 审批材料要求

- 一级：1 页执行摘要 + 资源需求
- 二级：完整 5 份报告 + 可行性结论
- 三级：1 页决策摘要 + 关键数字 + Go/No-Go 建议
