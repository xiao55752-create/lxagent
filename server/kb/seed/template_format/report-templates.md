# 市场分析报告模板

## 必须章节

1. 目标市场定义
2. 目标客户画像（含决策链）
3. 市场规模 TAM/SAM/SOM（标注来源或 estimated）
4. 市场趋势
5. 客户需求强度
6. 商业模式与定价假设
7. 关键结论

## 引用规范

- 有知识库来源：`[来源: 文档标题]`
- 合理估算：`[confidence: estimated]`
- 用户提供：`[confidence: user_input]`

# 竞品分析报告模板

## 必须章节

1. 竞争格局概述
2. 直接竞品分析（至少 3 家）
3. 功能对比矩阵
4. SWOT 分析
5. 差异化机会
6. 竞争策略建议

# 可行性分析报告模板

## 必须章节

1. 商业可行性（ROI、回本周期）
2. 技术可行性（能力缺口）
3. 运营可行性
4. 合规/法务
5. 风险清单（至少 5 项）
6. 综合评分与结论
