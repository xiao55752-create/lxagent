# 技术架构规范 v3.2

## 通用技术栈

| 层级 | 推荐选型 | 说明 |
|------|---------|------|
| 前端 | React + TypeScript + Ant Design | 统一 UI 规范 |
| 后端 | Python FastAPI / Node.js | 按团队能力选择 |
| AI 推理 | 支持 OpenAI 兼容 API + 国产模型 | 需通过安全评估 |
| 向量库 | Milvus / pgvector | RAG 场景必选 |
| 部署 | Docker + Kubernetes | 生产环境标准 |

## AI 项目特殊要求

1. **模型调用**：须配置成本上限与熔断机制
2. **数据安全**：生产数据不得用于模型训练；敏感数据需脱敏
3. **可观测性**：Agent 调用链、Token 消耗、检索命中率须可监控
4. **PoC 标准**：AI 类项目 PoC 阶段须验证核心指标（如准确率 > 95%）

## 技术评审关注点

- 是否存在团队能力缺口？缺口如何补齐？
- 第三方 API 依赖及备选方案
- 12 个月内技术债务评估
