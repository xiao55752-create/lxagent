# 2026 公司战略规划

## 核心战略方向

1. **垂直行业 AI Agent 平台化**：聚焦制造业、金融、零售三大行业，打造可复制的 Agent 解决方案模板。
2. **从工具到平台**：从单点 AI 功能升级为 Agent 编排平台，支持快速行业适配。
3. **数据安全与私有化**：面向企业客户提供私有化部署选项，满足数据不出厂/不出域要求。

## 年度目标

- AI 相关收入占比达到 30%
- 落地 3 个以上行业标杆案例
- 建立 Agent 开发平台能力，新项目交付周期缩短 40%

## 立项优先级原则

- P0：直接支撑年度战略目标的项目
- P1：提升平台能力、可复用的基础设施
- P2：探索性项目，需附条件立项且 PoC 预算不超过 50 万

## 资源约束

- 单个新品类项目首年预算上限建议 300 万
- 需跨部门协调超过 3 个团队的项目，须二级委员会审批
